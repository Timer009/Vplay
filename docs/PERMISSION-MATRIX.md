| 主体 \ 资源                         | 项目列表/详情 | 任务列表/详情                 | 任务日志    | Diff/回退 | 预览                  | Vision 报告/截图         | 证据包     |
| ----------------------------------- | ------------- | ----------------------------- | ----------- | --------- | --------------------- | ------------------------ | ---------- |
| 匿名                                | 401           | 401                           | 401         | 401       | 401（启用预览鉴权时） | 401                      | 401        |
| 管理员（主 Token / 管理员 Session） | 全部          | 全部                          | 全部        | 全部      | 全部                  | 全部                     | 全部       |
| 设备 A（授权项目 demo）             | 仅 demo       | demo 内全部任务（含他人创建） | demo 内任务 | 仅 demo   | 仅 demo               | 仅自己创建的 Vision 任务 | 仅自己任务 |
| 设备 A（未授权项目 secret）         | 403/不可见    | 403                           | 403         | 403       | 403/401               | 403                      | 403        |
| 同项目另一设备 B                    | 仅 demo       | demo 内全部任务               | demo 内任务 | 仅 demo   | 仅 demo               | **403**（私人证据）      | **403**    |

规则：

1. **协作面**：同一项目内，授权设备可查看共同工程的任务列表、详情、日志与 Diff（便于双端协同）。
2. **私人面**：Vision 报告、截图、任务证据包只对**创建者或管理员**开放；同项目其他设备不可读。
3. **未授权面**：未授权设备不得获得项目/任务元数据；`/status` 只返回其可见项目，且不回显 prompt。
4. **吊销**：设备吊销后，现有 Session、SSE 长连接、预览票据立即失效。
5. **幂等**：`idempotencyKey` 只在 `(createdBy, projectId)` 作用域内去重；跨作用域返回 409，不回显已有任务。
6. **预览**：`vplay_preview` 票据按项目路径授权；Vision 使用 5 分钟最小权限票据。
7. **SSE**：事件按 `projectId` 过滤；`Last-Event-ID` 补发；窗口截断时发送 `gap` 事件；连接数有上限。
